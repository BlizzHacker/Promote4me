# Social Media Commander Skill

This skill gives the agent command over social media marketing channels using Promote4.me.

## Available Actions
- `social_list_accounts`: List connected social media profiles.
- `social_post_now`: Publish post immediately with natural formatting.
- `social_schedule_post`: Schedule post with human-like jitter.
- `social_get_calendar`: View scheduled content across platforms.
- `social_get_comments`: Fetch recent comments needing attention.
- `social_reply_comment`: Post contextual reply to a comment.
- `social_get_messages`: Check inbound DMs.
- `social_send_message`: Reply to customer inquiry.
- `social_start_campaign`: Launch FollowLiker / MassPlanner style engagement.
- `social_check_limits`: Verify platform daily safety quotas.
